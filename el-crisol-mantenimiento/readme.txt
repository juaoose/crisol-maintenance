=== El Crisol - mantenimiento ===
Requires at least: 4.7
Requires PHP: 5.6
Stable tag: 2.0.1
License: GPLv2 or later

Página amarilla de mantenimiento de Importaciones El Crisol, con logo y datos
de contacto. Plugin independiente con un único ajuste para encenderla o apagarla.

== Installation ==
1. Sube el ZIP desde Plugins > Añadir nuevo > Subir plugin y actívalo.
2. Desactiva cualquier plugin anterior de mantenimiento.
3. Ve a Ajustes > Mantenimiento El Crisol, marca Mostrar la página de mantenimiento y guarda.
4. Borra la caché si la hay y comprueba la web en incógnito.

== Frequently Asked Questions ==
= ¿Cómo se apaga? =
Desmarca el ajuste y guarda, o desactiva el plugin.

= ¿Puedo seguir trabajando en el sitio? =
Sí. Los administradores con sesión iniciada ven la web normal.

= ¿Qué datos se guardan? =
Únicamente el estado del interruptor. Al desinstalar se elimina ese ajuste.
